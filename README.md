# bilgi yarismasi

🧠 Bilgi Yarışması Uygulaması 🎯

Bu proje, C# ve Windows Forms kullanılarak geliştirilmiş bir bilgi yarışması uygulamasıdır. Kullanıcıya sorular sorulur ve doğru/yanlış cevapları takip edilerek puanlama yapılır.

🚀 Özellikler:

✔️ Rastgele sorular ile dinamik deneyim

✔️ Doğru/yanlış sayacı ile puan takibi

✔️ Görsel geri bildirim (yeşil ışık doğru, kırmızı ışık yanlış)

✔️ Kolay ve anlaşılır arayüz
